jock reference
--diag

Machine interface

jockc.sh --diag emits one JSON object per run. The schema is pinned by corpus vectors that assert the exact string, so a change to it is deliberate and versioned rather than drift.

1. GENERATED — do not edit. tools/refgen.py in the compiler repo writes this page. channel %rc · commit f1c3be4 (sigilante/pre-rc-sweep) · corpus 1156 vectors · 2026-10-30

An agent driving the compiler should parse this rather than the human output, which is built for a terminal and whose alignment is meaningful.

Fields

FieldOn successOn refusal
status"ok""refused", or "crashed" with no tag
typethe program’s type, as a stringabsent
tagabsentthe refusal tag, without its %
line, colabsent1-indexed position; 0,0 means end of input
moduleabsentthe --data-dir module the refusal came from, or null
reportabsentthe human report, one string per line

Exit codes

CodeMeaning
0the program compiled (and ran, for run)
1refused or crashed — a JSON object was still emitted
2usage error: an unknown flag, or no mode given

1 and 0 both produce output. A tool should read status rather than branch on the exit code alone, since a refusal is a successful compile run that reports a rejection.
