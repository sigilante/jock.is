The beta channel

For reviewing developers

You have been handed a working Jock toolchain: a small terminal host called jojo and a kernel image, jojo.jam, which is the entire Jock compiler — compiled to Nock and running as an ordinary NockApp — in about 1.3 MB. Jock is a statically-typed language with a Swift- and Rust-flavored surface: structs, tagged unions, pattern matching, traits, classes, and generics, all of which erase to nouns and twelve instructions. This page is your orientation; everything on it was run against the exact image you received.

1. The bundle: the jojo repository (Rust, builds with cargo) with jojo.jam checked in. Nothing else is required.
2. The image carries no source text — the compiler rides as compiled Nock. What it does carry is the whole language, ready to type at.
3. Worked programs, with their expected values, live at jock.is. The language and type specifications travel separately with this bundle.

01 » Running it

Build and start the host from the jojo directory. It boots the committed image by default, or any kernel jam you hand it as an argument: 

cargo run                    #  boots jojo.jam
cargo run -- /path/to.jam    #  boots any trap jam
exit                         #  or :q, or Ctrl-D

The prompt reads one entry at a time. While your brackets are still open the prompt continues as  ...  and lines accumulate; the entry submits when they balance. A blank line at the continuation prompt cancels the pending entry. Boot takes a few seconds; each entry takes a few more — every answer is a full compile running inside Nock itself.

02 » A first session

The REPL follows one rule: an entry ending in ; is a statement — it is compiled, kept, and answered with ok — and anything else is an expression, evaluated against everything you have kept so far. 

jojo> let price = 42;
ok
jojo> price + 1
43

Definitions work the same way, across lines. Note the adjacency: the argument list is glued to the function name, and recursion is just the name. 

jojo> func fact(n: @) -> @ {
  ...   if n == 0 { 1 }
  ...   else { n * fact(n - 1) }
  ... };
ok
jojo> fact(10)
3.628.800
Numbers print dot-grouped, German-style, the way Hoon writes them.

Declare a shape of your own and match on it — and meet the floor of the language at the same time: 

jojo> union Color { red, green, yellow };
ok
jojo> func advance(c: Color) -> Color { match c { red => Color.green; green => Color.yellow; yellow => Color.red; } };
ok
jojo> advance(Color.red)
474.147.549.799
That number is the answer: Color.green erases to the atom whose bytes spell green, and the REPL shows you values as the nouns they are. Every Jock value is an atom or a pair, all the way down.

When you want to see the floor directly, :nock reveals the compiled formula of any expression: 

jojo> :nock 1 + 41
[8 [[9 [4 [0 68.719.476.734]]] [9 [2 [10 [[6 [[1 1] [1 41]]] [0 2]]]]]]]
Even + is honest: a gate fetched from the environment and kicked with the two operands.

The standard arithmetic and comparison operators are ambient. import hoon; additionally exposes the pinned Hoon interface (hoon.add, hoon.cat, hoon.rsh, and friends) for qualified calls at the FFI boundary.

03 » When it refuses

Jock fails loudly and exactly once. There is no error recovery and no cascade: the compiler stops at the first problem and names it with a tag and a position. This is deliberate — a single true error beats five speculative ones — and the tags are load-bearing: every refusal in the compiler's own test corpus asserts its exact tag, so what you see is a tested surface, not a formatting accident. 

jojo> nope
error: %mint-limb at col 1
jojo> func f(n: @) -> @ { n };
ok
jojo> f (2)
error: %parse-unglued at col 3
The second refusal is the adjacency law: f(2) is a call, f (2) is two expressions standing next to each other, and the language refuses to guess.

A failed statement changes nothing — your kept history is intact, and you simply try again. If an error message ever sends you the wrong way, that transcript is the single most valuable thing you can send back: the diagnostic hints grow from exactly such sessions.

04 » What to poke at

Anything, honestly — but the places where your judgment matters most are the edges. Push on the type system: declare structs and generic unions, write trait bounds, cast foreign nouns back into types with as? and as!, and see whether the rules land where your Swift or Rust instincts expect them. Push on the grammar: precedence, the adjacency law, non-associative comparisons. Push on the error reports: are the tags nameable, the positions right, the hints honest? The worked programs at jock.is make good starting points to retype, vary, and break.

Three edges are known and deliberate, so you do not spend your time rediscovering them: the shared image carries no importable modules beyond the pinned hoon interface; error reports are single-error by design; and each entry recompiles the session so far, so very long sessions slow down gradually.

Send whole transcripts back through the channel that delivered this bundle — what you typed, what it answered, and a sentence about what you expected instead. Surprise is signal. Thank you for reading this far, and enjoy the machine: it is small, it is honest, and it runs on twelve instructions.
